Scope and limits

Fixtures use the owned Herd site with both engines disabled. Real browser interaction covers exact map/deck pixel comparison, destination brief, ship report, pause and reduced motion, ship switching, expired arrival deadlines, route-only data and unknown data. Layouts include 320×568, 390×844, 844×390 and desktop. No arrival is inferred from the clock.

The first visual pass found a wrapping caption on short screens. The final pass keeps captions inside the scene and preserves a separate 44px ship-report control. An initial test run overlapped an asset build; the final full run used stable compiled assets and passed. Build and browser verification run sequentially.

No live gameplay was changed for this art update. Physical devices, Safari, Firefox and screen readers remain unverified. No merge or deployment was performed.
