Reproduce

Use the owned Herd fixture at spacetraders-map-90.test. Run node scripts/verify-system-map-actions-browser.mjs for actions and node scripts/verify-system-map-browser.mjs for stored browsing. Run the fixture-mutating suites sequentially. Set MAP_QA_OUTPUT to an ignored folder and MAP_QA_ONLY for a named action. Fixtures, credentials and raw environment files stay outside Git.
