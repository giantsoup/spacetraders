What is implemented

The dark flight deck separates engine state from run approval. Investigation reads one bounded system and explains observed candidates, prerequisites and missing information. Staging saves a revisioned draft. A 120-second preview binds fresh state, limits, reset and engine session. Duplicate approval starts that row once; material changes require a new preview.

Mining keeps one extraction per trip and checks each cycle’s confirmed contribution. Contracts support one existing offered or accepted procurement contract, one ship, same-system verified routes, explicitly included cargo and verified purchases. Acceptance, delivery and fulfillment use the same durable executor as manual commands. Timeouts preserve uncertainty and fresh contract evidence without replay.

Confirmed receipts, acquisitions, fuel costs and run cash contribution stay separate from total change from the recorded starting balance, manual activity and reviewed or unexplained changes. Unknown yield, price or duration stays unknown. Existing cargo’s direct-sale alternative and differences in fuel inventory remain visible.

Security review of the changed boundaries

The review covers the new routes, process control and shared mutation path. It is a source and synthetic-runtime assessment, not a full external penetration test or a new dependency audit.

  • Every new POST uses authentication and request-forgery middleware. Tests exercise real CSRF rejection, other owners, same-owner sibling agents and wrong resets. Nested records are queried through the selected agent and reset.
  • Engine operations require the configured local operator, exact local host and loopback address. The browser cannot choose a command, executable, PID or label. Fixed argument arrays invoke launchctl. The private service file is outside login LaunchAgents, with RunAtLoad and KeepAlive disabled.
  • Process liveness and the current session gate are checked before reservation. Gate closure and action reservation contend in a database transaction. End cancels unsent work; reserved or uncertain work remains evidence for reconciliation.
  • The executor checks fresh credits, protected cargo, location, fuel, equipment, approved contract step and progress. Each operation returns only its validated response fields. A delivery cannot invent an agent payment from extra response fields.
  • Agent credentials and the application key are absent from new responses and jobs. Vue renders evidence as escaped text. The service’s necessary application key stays in a private mode-0600 plist beneath a mode-0700 directory.

Issues corrected during implementation included launchd restart throttling, asynchronous removal confirmation, heartbeat-only health checks, changes between dispatch and reservation, per-cycle losses hidden by cumulative gains, and cross-operation response fields. Regression checks cover the corrected behavior. No unresolved security blocker was found within this scope.
