## Re-run

From this worktree in PowerShell:

```powershell
$env:PHP_BIN = "C:\Users\taylo\.config\herd\bin\php85\php.exe"
pnpm build
node scripts/verify-ship-scene-browser.mjs
node scripts/verify-native-ship-browser.mjs
& $env:PHP_BIN vendor/bin/phpunit
```

The browser scripts create isolated temporary SQLite fixtures and stop their own local servers.
Browser requests cannot reach external servers; PHP uses the synthetic HTTP transport. The scene
check produces 42 screenshots plus results.json here. Native UI evidence stays in
`storage/app/mvp-evidence/native-ui/browser/`. No development or production database is used.

The Herd-dependent art check was updated and syntax-checked, but not run: its required
`spacetraders-map-90` site is absent. No Herd settings or sites were changed.

## Visual review

Both approved HTML files were opened at 402 px wide. All requested scenes were reviewed
side by side with their approved references using the review sheets below. Round 2 also
regenerates byte for byte from the committed generator. The seven review sheets are derived
Pillow crops/contact sheets, not additional browser captures. They are not regenerated by
the browser script. Wide stationary scenes are centre-cropped; wide route scenes are reduced
proportionally. The full-page screenshots are the original evidence.

The 402x700 set deliberately has the 230px scene. The 402x620 set has the 128px scene.
The 402x560 set is safety-only, not a design approval. Campaign scenes remain 128px at all
viewport heights, including the extra 402x560 assertion without a separate screenshot.
