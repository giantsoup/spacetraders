Builds diverged before explicit source configuration; build-sources-red.txt reproduces changed output on old sources. The committed verify-build-sources.mjs now passes and root/fresh-copy assets match in a196c10.
  • Preexisting HEAD forwarding could initiate upstream writes without request-forgery validation. Independent reviewer reproduced HEAD-to-POST at a196c10. Native four-verb regression fails before the fix and passes with a permitted HEAD-read control. Commit 709700a restricts upstream writes to incoming POST; 89 backend tests and full real-Herd browser checks pass afterward.
